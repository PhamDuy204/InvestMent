# Root Cause Split — V29

The dominant root cause remains alpha instability rather than execution infrastructure.

H21-C teaches an important distinction: a feature can have a stable positive fitted coefficient and slightly improve prediction while still degrade portfolio economics through changes in ranking, turnover and wrong-side exposure. More model capacity is therefore not the next root-cause intervention.

The next research cycle should prioritize materially new information rather than additional transformations of the same observed H21-C family.
