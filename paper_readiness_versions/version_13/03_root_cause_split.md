# Root Cause Split — Simplified

## Problem statement

The strategy loses money because the **directional signal itself becomes wrong in at least one temporal regime**, not because execution cost alone erases a healthy edge.

## Split into four independent problems

### A. Alpha sign

Observed fact: aggregate H12 is already negative at 0 bps.

Therefore first-order equation is

`Net = GrossHolding + Funding - Cost`

and because `GrossHolding + Funding < 0` in aggregate, reducing `Cost` cannot by itself create a scientifically defensible directional edge.

### B. Temporal/regime instability

Fold 1 changes from strongly positive development/selection performance to negative held-out performance. Its LONG side is negative across every observed trend/vol/activity/session category examined.

Simplification: do not search 17-way threshold combinations. Ask whether one existing causal variable changes the **conditional expectation sign** consistently across time.

### C. Cost

10/20 bps worsen loss materially, so cost is secondary and must remain in all future gates. But cost optimization is downstream of restoring positive gross information.

### D. Timing

+60m degrades performance, yet 0m is already negative. Timing optimization is therefore not the dominant fix.

## Decision tree

1. If future development diagnostics show no positive conditional gross edge anywhere stable -> retire/replace H12 directional core.
2. If rank information survives but absolute sign fails -> investigate a causal relative/ranking formulation on development data.
3. If one low-dimensional causal state consistently flips sign across chronological slices -> consider exactly one regime interaction.
4. Only after a mechanism survives development gates -> freeze methodology and consider trial 871.
